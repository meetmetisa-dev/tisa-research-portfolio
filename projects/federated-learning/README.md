# Non-IID Multisite FedAvg

**Topic:** Federated Learning  
**Author:** Tisa Selma, Ph.D.  
**Status:** Reproducible synthetic research prototype - not a peer-reviewed publication or production system.

## Portfolio purpose

Eight heterogeneous synthetic sites collaboratively train a classifier without pooling records, with explicit worst-client and communication reporting.

This project is designed to demonstrate research reasoning, implementation quality, reproducibility, baseline discipline, and transparent limitations. It extends Tisa Selma's documented work in adaptive, explainable, multimodal, and drift-aware AI without representing the prototype as previously published evidence.

## Research question

How well does weighted federated averaging learn across heterogeneous sites when both global utility and the least-served client are part of the evaluation contract?

## Method

Client-specific feature shifts, scales, and label biases create non-IID local datasets. Clipped local logistic-regression updates are aggregated by weighted FedAvg and evaluated separately on each held-out client.

```bash
python validate.py
```

## Scientific contribution

The benchmark prioritizes per-client results, worst-client accuracy, cross-client dispersion, learning curves, and communication accounting rather than reporting only a global average.

## Limitations

Local data retention in this simulation is not equivalent to formal privacy. The prototype does not implement differential privacy, secure aggregation, poisoning resistance, or a confidentiality guarantee.

## Evidence boundary

The project is a portfolio prototype created in August 2026. It must not be described as a peer-reviewed result, a deployed system, a privacy guarantee, a clinical result, or evidence collected from real users. Any future empirical claim should be tied to a named dataset, versioned code, an approved evaluation protocol, and appropriate ethics or governance review.
