# Cooperative Edge QoE Control

**Topic:** Multi-Agent Reinforcement Learning  
**Author:** Tisa Selma, Ph.D.  
**Status:** Reproducible synthetic research prototype - not a peer-reviewed publication or production system.

## Portfolio purpose

A cooperative three-agent benchmark for resource allocation under changing demand, with shared reward, fairness, overload, and energy accounting.

This project is designed to demonstrate research reasoning, implementation quality, reproducibility, baseline discipline, and transparent limitations. It extends Tisa Selma's documented work in adaptive, explainable, multimodal, and drift-aware AI without representing the prototype as previously published evidence.

## Research question

Can cooperative resource agents adapt joint service levels to time-varying demand while controlling congestion and retaining fair service?

## Method

Centralized joint-action Q-learning over a transparent 27-state, 27-action synthetic environment. The learned policy is evaluated with matched seeds against random, demand-aware, and fixed-balanced baselines.

## Reproduce

```bash
python -m pip install -r requirements.txt
python demo.py --check --output results.json
python validate.py
```

## Scientific contribution

The prototype demonstrates multi-agent state/action construction, shared-reward design, fairness-aware evaluation, baseline discipline, and reproducible reporting. A strong fixed baseline is retained even when it slightly outperforms the learned controller.

## Limitations

Synthetic demand only. The centralized joint-action formulation does not scale to large agent populations, and no latency, safety, or production-deployment claim is made.

## Evidence boundary

The project is a portfolio prototype created in August 2026. It must not be described as a peer-reviewed result, a deployed system, a privacy guarantee, a clinical result, or evidence collected from real users. Any future empirical claim should be tied to a named dataset, versioned code, an approved evaluation protocol, and appropriate ethics or governance review.
