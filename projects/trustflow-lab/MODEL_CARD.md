# Model card — TrustFlow Lab

The current score is an interpretable weighted rule with a threshold calibrated from benign training-period scores. It is not a production intrusion detector.

The demonstration is suitable for evaluating the alerting contract. It is not suitable for blocking traffic, attributing attacks, employee monitoring or automated disciplinary decisions.

A production candidate needs adversarial testing, cross-network validation, explainability review, alert-budget analysis, human escalation and rollback procedures.
