# Data card — CipherQoE

The committed fixture contains only generated aggregates: session duration, uplink/downlink byte totals, packet count, mean packet size, RTT and burstiness. It excludes packet payloads, URLs, account identifiers, IP addresses and device identifiers.

Real traces can still expose behavior and must be minimized, access-controlled and deleted on a documented schedule. Public examples should be locally generated or licensed for redistribution.
