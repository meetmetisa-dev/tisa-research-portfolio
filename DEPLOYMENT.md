# Publish the portfolio

## GitHub repository

1. Create a public repository named `tisa-research-portfolio` under `github.com/meetmetisa-dev`.
2. Upload this folder or push its initial commit to the `main` branch.
3. In **Settings → Pages**, set the source to **GitHub Actions**.
4. Open the `deploy-portfolio` workflow and confirm the published URL.

The workflow uploads only `website/`; application drafts and private source data are not part of this repository.

## Before the first publish

- Confirm the preferred GitHub username and update source links if needed.
- Confirm the public degree wording and publication statuses.
- Review the public CV at `website/assets/Tisa_Selma_Research_CV.pdf`.
- Do not add participant-level, institutional or confidential operational data.
